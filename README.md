It's the Zombie Apocalypse and you are doing pretty well. You've got several heavy duty turrets that keep those rotting walkers at bay. But wait! Some idiot has taken all the chips and bolts out of the computer that controls the turrets. You must find them and repair the computer or you're toast.

#### Controls:
WASD - move

E - Pickup items

Right Mouse Button - Switch between items

Left Mouse Button - Attack

Space - Dash
